# ZCP2O Brand Identity & Visual Guidelines

## 🌱 Color Philosophy
ZCP2O utilizes **Light Green** as its primary identity. This is not a random choice; it is rooted in our core philosophy:
1. **Go Green & Eco-Friendly:** Proof-of-Play requires no energy-wasting computations, unlike Proof-of-Work.
2. **Organic Growth:** The Mesh Network grows naturally from user to user, much like roots or mycelium in a forest.
3. **Resilience:** Like a tree that survives a storm, ZCP2O's local architecture remains alive and functional even when the global internet "storm" hits.

## 🎯 Official Color Palette

### Primary: ZCP2O Green (Cyber Mint)
- **Hex:** `#00E676`
- **RGB:** `0, 230, 118`
- **Usage:** Logos, primary action buttons (Play, Confirm), active states, and highlights. It pops beautifully against dark backgrounds.

### Secondary: Deep Root (Dark Green)
- **Hex:** `#064E3B`
- **RGB:** `6, 78, 59`
- **Usage:** Backgrounds, UI panels, and dark mode bases. Provides strong contrast.

### Accent: Pure White
- **Hex:** `#FFFFFF`
- **Usage:** Primary typography, icons, and borders for maximum readability.

## 🆚 Market Positioning by Color
- **Bitcoin** = Orange (Digital Gold, Energy)
- **Ethereum** = Purple (High Tech, Ether)
- **BNB/BSC** = Yellow (Commercial, Trade)
- **ZCP2O** = **Light Green (Life, Access, & Resilience)**
