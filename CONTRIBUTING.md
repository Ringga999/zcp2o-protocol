# 🤝 Contributing to ZCP2O Protocol

Thank you for your interest in building the offline-first, zero-capital sovereign blockchain with us!

## How to Contribute

1. **Fork the Repository**  
   Create your own fork of `zcp2o-protocol` and clone it locally.

2. **Create a Branch**  
   Use a descriptive name: `feat/your-feature` or `fix/your-bug`.

3. **Make Your Changes**  
   - Ensure your code follows the existing style.
   - Add tests if applicable (run `pytest` in `implementations/zcp2o-core`).
   - Update documentation if you change any public APIs or specs.

4. **Submit a Pull Request**  
   Provide a clear description of what your PR does and why it's needed. Link any related issues.

## Code of Conduct
We are building a protocol for the unconnected world. Respect, inclusivity, and a focus on privacy-first design are mandatory.

## Need Help?
Open an issue with the `question` label, or reach out to the maintainers.
