Why This Matters

SRI ensures that even if an attacker compromises the CDN or GitHub Pages, they cannot inject malicious code into your widget — the browser will reject any file whose hash doesn't match.

How to Generate Correct Hashes

# PowerShell (Windows)
curl.exe -o temp.js "https://ringga999.github.io/zcp2o-protocol/implementations/zcp2o-captcha/widget/zcp2o-human-proof.js"
$hash = (Get-FileHash -Algorithm SHA384 temp.js).Hash
[System.Convert]::ToBase64String([System.Convert]::FromHexString($hash))

# Linux/Mac
curl -o temp.js "https://ringga999.github.io/zcp2o-protocol/implementations/zcp2o-captcha/widget/zcp2o-human-proof.js"
openssl dgst -sha384 -binary temp.js | openssl base64 -A

⚠️ Important: Always generate hashes from the deployed file (GitHub Pages), not your local copy. Local files may have different line endings (CRLF vs LF) that change the hash.
