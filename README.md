# 🌱 ZCP2O Protocol

**Zero-Capital Play-to-Own: The Offline-First Blockchain for Everyone.**

[![License: MIT](https://img.shields.io/badge/License-MIT-00E676.svg)](https://opensource.org/licenses/MIT)

## 🎯 What is ZCP2O?
ZCP2O is an offline-first blockchain protocol that allows anyone to transact, communicate, and earn rewards without needing an initial capital investment or a stable global internet connection. 

Unlike Bitcoin (Proof-of-Work) or Ethereum (Proof-of-Stake), ZCP2O utilizes **Proof-of-Play (PoP)**, where block validation is driven by real-world human activity (gaming, message relaying, learning).

## ✨ Philosophy & Identity
ZCP2O adopts **Light Green (`#00E676`)** as its primary identity, symbolizing:
1. **Go Green:** An eco-friendly consensus mechanism (zero energy waste).
2. **Organic Growth:** A mesh network that grows naturally from user to user, like roots.
3. **Resilience:** Surviving and thriving like a tree even when the "storm" (internet blackout) hits.
